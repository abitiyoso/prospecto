# Prospecto Interactive Landing v7

- Open `index.html` with its `assets/` folder and `workspace.html` next to it, or use `Prospecto_Landing_Interactive_v7.html` for an all-in-one version.
- Logo: exact approved original `Prospecto_Approved_Logo.png` (copied unchanged to assets). Do not redraw.
- Hero: original approved 4-character artwork, with embedded subtitle/CTA from source artwork cleared in favor of real HTML text/buttons. Desktop hero fills the viewport, mobile portraits are swipeable and clickable.
- Main tabs: Product KMS, Prospect Finder, PIC Finder, Campaign Builder, Analytics. Interactions are client-side and do not claim actual external lookup/send.
- `workspace.html` is the supplied Prospecto v15 workspace, preserved as supplied and loaded in the embedded showcase and full-screen overlay.
- CSV uploader is local file preview; does not upload to a server. LEO answers in landing are predefined suggestions. The v15 workspace uses its own simulated client-side data and is not a live Firecrawl/Composio/LinkedIn backend.
- Navigation links, pricing, trial/free CTAs, and enterprise commercial terms should be reviewed before production deployment.
- Desktop 1440/1024 and mobile 390/320 layouts tested using Chromium in a rendered, asset-inlined fixture. No horizontal overflow or page errors observed in tested scenarios.
